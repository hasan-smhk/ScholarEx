# ScholarEx

## Features

- Classes 1–10 for CBSE, ICSE, and Karnataka State Board
- Expandable class cards with subject lists and descriptions
- Level filters for Primary, Secondary, Pre-Board, and Board Exam
- Kannada/English content toggle for Karnataka State Board classes
- Responsive course pages with consistent `PageBackground` theming
- Shared class content in `frontend/src/data/courseData.ts` for quick updates across board pages
